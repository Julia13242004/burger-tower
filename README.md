# Chef Burger

Мобильная браузерная игра на реакцию. [Играть](https://julia13242004.github.io/burger-tower/).

## Как играть

1. Нажми «Начать игру». На столе уже лежит нижняя булочка.
2. Коснись игрового поля или нажми кнопку «Положить слой», когда ингредиент окажется над верхушкой башни. На компьютере также можно нажать пробел.
3. Если ингредиент лёг со смещением, выступающая часть отрезается, а остальное остаётся на башне. При полном промахе бургер закрывается верхней булочкой.
4. На высоте 1 м открывается подарок — книга «Азбука вкуса» Карен Пейдж и Эндрю Дорненбурга.

Ингредиенты ускоряются по мере игры, даже если подождать на одном слое. Высота учитывает оба слоя булочки. Рекорд сохраняется в браузере на устройстве игрока.

## Локальный запуск

В корне проекта запусти `python3 -m http.server 8000` и открой <http://localhost:8000>. Сборка и зависимости не нужны. GitHub Pages публикует файлы из корня ветки `main`.
